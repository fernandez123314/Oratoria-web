# Oratoria Web

Bienvenido al repositorio de **Oratoria Web**, una plataforma diseñada para ofrecer servicios de oratoria y comunicación. Este proyecto tiene como objetivo proporcionar una interfaz amigable para que los usuarios puedan contactarnos, conocer nuestros servicios y acceder a recursos útiles.

## Características

- Sección de contacto con un formulario para enviar mensajes.
- Información sobre horarios de atención y ubicación.
- Sección de servicios y testimonios.
- Diseño responsivo para dispositivos móviles.

## Tecnologías Utilizadas

- **HTML5**: Para la estructura del contenido.
- **CSS3**: Para el diseño y estilo de la página.
- **JavaScript**: Para la funcionalidad interactiva, como el menú desplegable en dispositivos móviles.

## Instalación

Para ejecutar el proyecto en tu máquina local, sigue estos pasos:

1. Clona el repositorio:

bash
   git clone https://github.com/fernandez123314/Oratoria-web.git

2. Navega al directorio del proyecto:  
bash
   cd Oratoria-web

3. Abre el archivo `index.html` en tu navegador web.

## Uso

- **Formulario de contacto**: Los usuarios pueden enviar consultas y mensajes a través del formulario de contacto.
- **Información adicional**: Los usuarios pueden encontrar detalles sobre horarios de atención y ubicación.
